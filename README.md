## Descrição

Este trabalho contém a implementação da camada de apresentação para servir o segundo trabalho da disciplina de Engenharia de Software I.

## Implementação

O código foi escrito em HTML, CSS e Javascript. O código em Javascript foi separado em diferentes módulos para uma melhor visualização e busca. A camada de apresentação contém apenas o visual do que o usuário irá observar, portanto, não há dados pré-definidos.
